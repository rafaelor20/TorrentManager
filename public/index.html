Abstração TorrentClient

Contrato desacoplado e extensível

A interface TorrentClient define os métodos fundamentais para qualquer cliente BitTorrent sem amarrar as regras de negócio:

async conectar() Autenticação e handshake com a Web API
async listarTorrents() Listagem unificada e status dos downloads
async listarArquivos() Mapeamento da árvore de arquivos e progresso
async alterarPrioridades() Controle seletivo de prioridades de download
💡
Substituição Imediata: Para alterar a implementação ou adicionar novos clientes (Transmission, Deluge), basta instanciar outra classe que implemente a interface TorrentClient.
